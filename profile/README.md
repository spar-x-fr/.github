# Spar-x

**Cabinet agentique coopératif : conseil humain et agents IA, avec une activité de formation certifiée Qualiopi.**

Nous aidons les dirigeants et les équipes techniques à mettre des agents IA en production : fiables, vérifiés et maîtrisés en coût.

## Open source

| Dépôt | Ce qu'il apporte |
|---|---|
| [spar-x-skills](https://github.com/spar-x-fr/spar-x-skills) | Skills Claude Code prêtes pour la production. Première skill : `rightsize`, la qualité d'un expert avec le bon modèle, le bon effort et des vérifications proportionnées à chaque étape. |

Installation dans Claude Code :

```
/plugin marketplace add spar-x-fr/spar-x-skills
/plugin install spar-x-skills@spar-x-skills
```

## Formations
